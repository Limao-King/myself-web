# 项目列表页评审清单

1. **[严重度：高] 底部中央悬浮 dock** — 两个滚动位置截图中，深色圆形 dock 都被视口下边缘齐齐斩断、只露出上半截（图标与红色小红点均在，下半截不可见）。固定定位元素每一屏都以“切半”状态出现，是最显眼的可见 bug。 — 检查该 dock 的 `position: fixed` 的 `bottom`/`transform`，疑似存在负偏移或 `translateY(50%)`；让它完整落在视口内（如 `bottom: 20px`）。

2. **[严重度：中] 右上卡片「唤她真名（心理悬疑动画剧本）」标题** — 换行后第二行只剩「本）」两个字符的孤字悬挂，全角括号吊在行尾非常扎眼；「乱世三国（Minecraft RPG 地图）」同样把「地图）」甩到第二行。 — 对卡片标题加 `text-wrap: balance`，或手动控制断行/缩短主标题（如主标题「唤她真名」+ 副题放 eyebrow 行），保证左右相邻卡标题行数一致。

3. **[严重度：中] 页脚区域** — 高饱和绿色像素纹理在一条硬直线上突然切到平坦米色，之后是一大片几乎全空的留白 + 一根细线 + 一行版权，与上方信息密度形成强烈落差，显得未完成。 — 给图案→页脚的过渡做像素化抖动（dither）边界或延续面板描边语言；页脚内补充迷你导航/像素装饰/返回顶部链接，压缩空白高度。

4. **[严重度：中] 右列两张卡片的简介截断** — 「负责结局（12、13 节）。后…」「…借鉴了许多游戏的系统以辅助地图…」均为 CSS line-clamp 在半句话处生硬切断，省略号前语义残缺；左列两卡却是完整句，左右观感不统一。 — 改为每卡手写定长摘要（人为控制收尾在句号处），或按句子边界截断，保证四卡结尾节奏一致。

5. **[严重度：中] 「唤她真名」缩略图** — 深色织锦照片在奶白卡片里近乎一块黑斑，主体（人物图案）在缩略图尺寸下不可辨，且与其他三张明亮、色彩鲜艳的截图（蓝天、绿野、暖色室内）调性脱节，拖累整版面的均衡。 — 换更亮、更近景的一帧；或对四张缩略图统一加暖色调/描边画框处理，把暗图纳入整体配色。

6. **[严重度：低] 页面背景绿色菱形纹理** — 白色图案对比度过高、排布过密，持续与内容争夺注意力，且与导航条同色相导致导航边界发糊；羊皮纸主面板反而被压住。 — 将纹理中的白色降为低饱和米色、整体明度压暗 10–15%，或降低图案不透明度，让中央面板更突出。

7. **[严重度：低] 卡片一缩略图与标题命名不一致** — 缩略图内标题画面写着「童话回合历险」，卡片标题是「童话冒险 DEMO」，同一卡两个名字并置像两个不同项目。 — 统一命名，或换一张不含标题画面的游戏内截图。

8. **[严重度：低] 右上角「WORK LOG」圆形印章** — 浅红色描边在奶油底上存在感过弱，旋转角度随意，目前更像渲染瑕疵而非装饰章。 — 加深印泥色、边缘做残缺/粗糙遮罩模拟盖章质感，并让其角度与面板圆角形成呼应。

**总体**：配色体系统一（绿×羊皮纸×铁锈红）、卡片网格等宽等距、行内 CTA 底对齐、文字对比度全部达标，骨架是健康的。要冲 90+，优先修悬浮 dock 截断（1）和标题孤字（2）这两个一眼可见的硬伤，再处理页脚收尾（3）与缩略图调性（5、7）。
