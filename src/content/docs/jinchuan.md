# 红楼梦金钏之死改编

《红楼梦》「金钏之死」片段的戏剧剧本改编。

**重要人物表**（节选）：
- **宝玉**：贾府玉字辈嫡孙，受贾母疼爱，性格叛逆，对追求仕途经济极为反感，心思细腻，对金钏颇为关心。
- **金钏**：王夫人的贴身丫鬟，性格直爽大方，与宝玉关系较好，言语间偶尔流露出俏皮和大胆。
- **王夫人**：宝玉的母亲，表面吃斋念佛，实则为人刻板、严厉，对丫鬟们要求苛刻。
- **玉钏**：金钏的妹妹，同样在王夫人身边当差。
