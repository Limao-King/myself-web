# 男良

改编自李渔《无声戏：男孟母教合三迁》。

节选（开场）：

### 礼堂　日　现今　内

在一方各类婚庆相关的装饰布置地井然有序的大礼堂里，长椅上几乎落满了人。礼堂前方的台侧，司仪拿着稿子在熟悉，新娘则含笑望着站在台上的许承先。

许承先平静好自己的呼吸，看着稿子。

许承先：人们常说，十年树木，百年树人。一个人到底要长成什么样的人，离不开一个家庭对他的教育与塑造。

许承先理了理稿子。

许承先：我不是人们口中有天赋的好孩子，也不认为自己有什么过人的本领，我能走到现在，能拥有幸福美满的家庭，都离不开我的母亲，因此，我首先要感谢我的母亲……

许承先的眼神先是凝向前方，随后又散了开来，像是有点走神，但嘴角是浅浅的微笑。

### 许宅院子　日　过去　外

院内一张木桌上置着一个果篮，篮中装满了桃子。许承先从屋内惊慌地跑出，其母亲尤瑞良表情愤怒，拿着衣架追了出来。

尤瑞良：我数 321，听到没有？

许承先好像触了电一般，低头杵在原地。

尤瑞良：这一次，你知道自己错在哪里吗？

许承先：老师说是这次考好的奖励。

尤瑞良：他说是奖励就是奖励，别的同学他给了吗？还隔三差五就给你送，哪有这种天上掉馅饼的好事。
