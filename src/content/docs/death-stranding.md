# 连结孤独的岛——《死亡搁浅》中的异步联机系统拆解

## 一、所选游戏、系统与位置

《死亡搁浅》的核心玩法是"送货"：派送员 Sam 穿越被时间雨、BT 与险峻地形割裂的末日美国，把物资送到各个据点。

我选择拆解的是它的异步联机系统。在这套系统中，其他玩家的建筑（梯子、攀爬柱、储物柜、桥、充电桩、安全屋、滑索、雨亭）、公路、载具与掉落的货物，会以"痕迹"的形式出现在我的世界里；我可以使用、点赞、维修它们，自己建造的设施也会同样服务其他玩家。

它在整体体验中的位置：异步联机虽然不直接参与送货的核心操作（规划路线、负重管理、克服地形），但它却是覆盖在核心循环之上的一层"长线建设辅助系统"，塑造了游戏的世界氛围，让玩家在这个历经死亡搁浅的孤寂世界中，隐隐能感觉到一种与他人连结的感觉。是游戏"连接"主题的玩法性表达。

## 三、设计意图

**解决的玩家需求**：① 单人送货途中可能会产生的孤独感；② 虽然不想承受实时社交的压力，但玩家也希望被看见。

**强化的核心乐趣**：地形克服与路线规划因为"需要考虑网络中刷新的建筑节点"而更有策略深度；同时这套玩法鼓励发现"利他"的快乐——设施的使用与帮助都会产生玩家的正反馈。

**承担的各类作用**：
- **留存**：修路、滑索网、赞数与等级构成长线目标，"去看看我的建筑今天收获了多少人的赞"成为回游理由。
- **成长**：赞数 → 配送等级（五维评价，每 10 级强化能力面板）→ 可签的斯特兰德契约数量上限提升（契约对象的建筑更常出现在自己世界）。
- **社交**：弱社交，虽然创造了玩家与玩家互利的手段，但没有打造明确的交友转化口，目前情况是可以以收到的点赞数量化连结。
- **竞争**：每一次随机联机时会有连接到的玩家中收到赞数的高低，但没有激发与它人竞技欲望的服务器总榜，强调自我因与它人连结的渴望所激发的自驱。
- **商业化**：游戏是买断制游戏，这套设计并不是基于商业化考量所建构的。但是它的社交改造潜力很大，如果可以运用地好，可以实现系统的商业性转化。

## 四、关键变量与规则

| 题面维度 | 变量/规则 | 具体表现与设计目的 |
| --- | --- | --- |
| 消耗与产出 | 建造材料 / 赞数 | 建桥、铺路消耗金属、陶瓷等；使用与帮助产出赞，赞是"社交货币" |
| 次数限制 | 开罗尔带宽 | 每个区域独立上限（如中部区域约 4 万量级，滑索一座占 500）；建造消耗、拆除返还——防建筑泛滥、保留地形挑战 |
| 匹配/难度 | 网络覆盖 + 同步筛选 | 未接入网络的区域不显示他人痕迹；服务器只抽样同步部分玩家的建筑——控制世界密度，平衡孤独氛围与探索难度 |
| 奖励分层 | 送达评价 S~C、赞数、等级 | 订单完成按货物完好度分层评价；赞累积推等级，等级解锁更多契约位与功能 |
| 时间节奏 | 耐久与时间雨 | 设施随时间雨/时间侵蚀损耗，需材料维修或他人帮助——制造维护循环与"新陈代谢" |
| 阶段目标 | 接入结点 / 铺路工程 | 每个新据点接入网络=新阶段；高速公路的修建它人的材料捐赠最多只能助力一半，需要玩家自己继续收集材料兴建该路段。 |

## 五、优缺点

**优点**：
1. **异步轻社交**：不需要同时在线、规避了实时多人的压力与成本。它人的帮助可以送达，基建可以共用，它人的建筑可以被点赞，营造了与他人连接的氛围感。
2. **点赞体系驱动玩家自驱建造**，维护基建。

**不足**：
1. **"被需要"不可见**：我的桥被用了多少次、帮了谁，通常要进菜单看累计数字，缺少即时体感。
2. **后期边际递减**：赞刷多了会麻木，公路和滑索网完成后，建设动力明显下滑。
3. 出于设计主题和氛围要求，与它人的连接程度被严格控制，这套系统并没有被设计连接之后的关系转化，即玩家无法通过这套连接交友，如运用到其他游戏中需要适当改造。

## 六、优化与扩展思考

**优化点**：如果我是策划，我会增加"利他"的即时反馈强度，上线期间，当我的设施被其他玩家使用时，推送轻量通知（"你的梯子今天帮助了 17 位派送员"），并允许一键"感谢回赞"。以轻量的 UI/通知改动改善玩家收到的即时反馈；这也是把该系统迁移到商业游戏时，最值得保留并升级的一环。

**拓展思考**：这套异步联机系统底子优良。点赞驱动下，互助互利的机制很好地以系统体现了连结的主题，与游戏本体适应性良好。但是系统如果需要应用到商业化游戏中，就要思考商业化改造的可能性，这里假设要迁移到某可以基建的 SLG 游戏，简单列思考路径：

A 派出农民采集资源，开启采集计时器 → 使用某陌生人 B 选择共享的设施后，A 提升资源采集效率，B 得到点赞反馈 → B 的设施在 A 世界刷新概率提高，这种概率以连接度量化 → 连接度到达一定量级，彼此可以发起好友申请，实现从连接到社交好友的飞跃 → 成为好友后 A、B 可以每天固定共享设施（有额度），加深连接。
