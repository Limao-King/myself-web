# 童话冒险 DEMO 主策划案

## 1 项目概览

### 1.1 项目名称
后面再取名（暂代号童话冒险）。

### 1.2 定位介绍
使用 Godot 引擎制作，发布在 PC 平台，讲述一对兄妹穿越童话世界各个区域、到达城堡、击败恶魔的回合制战斗 RPG。

### 1.3 受众 & 参考
目标受众：偏好剧情驱动、慢节奏的回合制 RPG，以及喜爱复古像素与童话氛围的休闲玩家。
参考对标：战斗与探索节奏参考《勇者斗恶龙 11S》与《Look Outside》；在童话日常与现实世界交织的叙事气质上参考了《地球冒险（EarthBound）》系列。

### 1.4 核心循环
区域探索 → 战斗 → 成长 → 探索新区域。

### 1.5 剧情概述
**序章**：猎户父亲康拉德出门打猎，无聊的汉斯和安娜想要出门探险，去寻找据说成为了贵族的妈妈。在路上伙伴皮皮加入，他们在森林里遇到了各种各样的童话生物，一位被他们打败的卑鄙精怪告诉他们魔女芭芭拉的诡计，他们踏上了前往城堡的路。

### 1.6 世界观概况
一个具有各种童话生物的世界，但描绘这些生物的笔触比较写实，赋予他们品格与习性。世界由汉斯和安娜两兄妹的母亲玛利亚用她的想象力所创造，兄妹俩的最终目标是重新见到母亲；目前他们对血脉与母亲的能力暂且不知。

### 1.7 关键备注
- 640×360 像素分辨率
- 2D 俯视角探索 + 独立正面战斗
- 16×16 像素美术风格，整体明亮
- 仿 GBA / SFC 时期音乐音效
- 剧情基调清新、明快、治愈，略有一些黑暗伏笔

## 2 系统概况

### 2.1 系统面板
- **概况**：其他各个系统的连接点，探索中按 C 键唤出；呼出后游戏状态暂停，包含 继续/角色/队伍/背包/设置/标题/结束 选项。
- **设计**：黑白像素方框，每个选项一行，选项文字皆为白色像素字体。
- **出口**：ESC 退出；点击继续/标题/结束 退出。
- **联动**：作为其他系统的出入点。

### 2.2 战斗
- **概况**：根据速度值决定行动顺序，为角色指定合理指令；我方角色血量归零则战斗失败。
- **入口**：探索中触碰明雷式敌人；或通过剧情、事件、NPC 对话切入。
- **流程与细则**：
  1. 初始化：上方居中宣告实时战斗信息，中央显示敌人图像，下方以方框区分显示我方角色名称与状态，左侧为我方指令菜单；按速度排列行动顺序，各单位依次行动。
  2. 敌方行动：可能攻击 / 蓄力 / 发动技能 / 跳过回合 / 移动。
  3. 我方行动：每回合 1 次指令，5 个选项——攻击（不耗 MP，物理伤害）/ 技能（消耗 SP，伤害类型各异）/ 道具 / 防御（减免 50% 下一次行动前受到的伤害）/ 逃跑（非必败战役必定成功，全员跳过本回合）。
  4. 全员行动完毕后按实时速度排下一轮，直至一方全灭判定胜负。
- **伤害计算**：
  ```
  物理伤害 = max(攻击力×0.6 − 防御力×0.4, 攻击力×0.15)
  想象伤害 = max(想象力×0.6 − 精神力×0.4, 想象力×0.15)
  ```
- **命中与距离**：`命中率 = clamp(85% + (攻方灵巧−守方灵巧)×2% − 距离惩罚, 5%, 100%)`
  - 近距离攻击打中距离敌人 −25%（带「中距离」标记无惩罚）；敌人打我方无惩罚。
- **速度与行动顺序**：按速度降序；同速时我方先手概率约 85%（伪随机）。
- **状态**：属性增减 / 流血 / 中毒 / 眩晕（STUN）。
- **战斗距离**：近/中两种距离；进入战斗默认中距离；怪物可移动改变距离，玩家靠技能/道具击退或拉近；无「中距离」标记的行动打中距离敌人受命中惩罚。
- **多敌人战斗**：敌人由「敌人组」（EnemyGroup）组合，每项为某敌×N；单体技能需手动选目标，群体技能（ALL）对全体独立判命中、独立结算。
- **敌人 AI 范式**：按角色防御/生命/灵巧计算受攻击加权分；预埋 8 种 AI 范式——鲁莽 / 逼近者 / 规律技击 / 随机技击 / 蓄力怪 / 间歇跳过 / 远程压制 / 权重随机；特殊怪物装配专属 AI。
- **队友倒地**：HP 归零显示「倒地」，行动轮结束后再经过三个完整行动轮恢复 10% 最大生命值重新加入；只有全员归零才判负；带倒地胜利时战后恢复至 10%。
- **战斗奖励**：胜利后除经验、金币外，敌人有概率掉落道具/装备。
- **出口**：胜利回到探索原位、敌人消失；失败一般直接 GameOver。

### 2.3 身份
- **概况**：角色详情中显示身份，不同身份特性不同；定位包含物理输出 / 法术输出 / 承伤 / 辅助（设计层面，不明确写出）。
- **身份类别（DEMO）**：安娜＝巧匠女孩（中距物理输出）；汉斯＝猎户之子（近距输出承伤）；皮皮＝宝藏猎人（辅助混伤）。
- **属性**：HP / SP（想象点）；攻击力 / 防御力；想象力 / 精神力；速度 / 灵巧。攻击力与想象力分别影响物理/想象伤害，防御力与精神力分别减免对应伤害，速度决定行动顺序，灵巧影响命中。
- **技能**：字段＝id/名称/SP/伤害类型/目标（SINGLE/ALL）/威力（百分比倍率，100=1 倍）/段数/蓄力/距离/推拉/附带状态。解锁（方案 D）：开局自带 + 对应等级解锁。

### 2.4 队伍
- **概况**：调整队伍排序、配置出战队员、设置 AI 托管。
- **出战成员**：八个格子，前四个为出战（左上角标标识），后四个备战；汉斯顺序恒为第一（不可备战），出战第二的成员是「先锋」，获得 10% 速度加成。
- **AI 托管**：手动操作 / 自动攻击 / 自动战斗；任何托管都不会自动使用道具。
- **联动**：出战顺序影响探索时大地图行走形象排列。
- **成员招募（增补）**：完成支线/推进剧情入队；入队等级＝（汉斯+安娜当前等级）/2 向下取整，解锁对应技能，属性自动成长。

### 2.5 装备
- **概况**：一位角色可装备一件武器、一件护具、一个宝藏；宝藏猎人皮皮可装备两个宝藏。
- **装备类型**：武器按距离分近/中距、按伤害分物理/想象，特殊武器解锁技能并限制角色；护具增加承伤、限制角色；宝藏提供属性加成或解锁技能，一般不限定角色。

### 2.6 背包
- **概况**：显示金钱数量；四个类目——装备/道具/杂物/重要物品；选中显示描述。
- **联动**：战斗道具指令调用背包；商店购物/出售增减金钱。

### 2.7 探索
- **概况**：WASD 移动、镜头跟随；E/ENTER 交互；触碰敌人切入战斗；篝火可消耗露营套装露营。
- **交互物一览（增补）**：NPC（对话）、商人（商店）、宝箱、篝火（露营）、存档点（手动存档）、检视点（一次性对话）、收集物、传送门、门与机关。
- **篝火露营**：消耗露营套装补满全队 HP/SP。
- **探索镜头**：Phantom Camera 插件——正常跟随玩家，房间设定死区固定镜头，过场自由调度演出。

### 2.8 对话
- **概况**：探索或剧情播放时下方浮现对话框，含角色名称与文本。
- **流程**：一句接一句，全部播完后再点关闭。

### 2.9 存档
- 自动存档（单槽，关键节点覆盖）+ 手动存档（6 槽，存档点交互）。DEMO 完案：暂时移除自动存档。

### 2.10 商店
- 面板含 对话 / 购买 / 出售 / 返回；购买/出售价格 = 道具价值 × 商人内置购买/出售系数；与背包联动。

## 3 数值成长（DEMO）
小数字量级 + 线性成长，追求清晰可控的战斗节奏。

- **战斗时长**：普通怪 1.5 分钟 / 精英 3 分钟 / BOSS 5–10 分钟。
- **升级节奏**：序章角色大约升到 7 级。
- **经验曲线（DEMO）**：

| 5 级 | 85 | 210 |
| 6 级 | 110 | 320 |
| 7 级 | 150 | 470 |
| 8 级 | 250 | 720 |

- **每场经验**：普通怪 15、精英 45、无 BOSS（有 BOSS 再定）。

## 4 关卡流程（DEMO 内容）
- **收集物**：宝箱可开出装备与道具。
- **序章**：开场（音乐+背景介绍）→ 教程（移动/对话/基础战斗）→ 小屋区域（探索收集，无战斗）→ 森林区域（探索+战斗，皮皮入队成三人小队）→ 击败守关精英「卑鄙的佩姆」后 DEMO 完成。

## 5 素材资源
- **美术**：整体素材简单易用，Nearest 过滤保证像素清晰；tile 16×16、敌人战斗立绘 64×64、探索人物精灵图 24×32（4 方向×3 帧）。
- **音乐**：探索/普通战斗/精英战斗各寻一段匹配情绪的音乐；含攻击/受击/技能/菜单/升级/对话框等声效。

## 6 实现方案
- **引擎**：Godot 4.7 / GDScript。
- **数据**：Resource（.tres，CSV 驱动生成，无 uid）；对白 JSON（md 转换）。
- **信号**：GameManager / EventBus / InteractionHint / AudioManager / SystemPanel / DialogBox / ConfirmBox / SaveManager / SaveSlotUI / PhantomCameraManager。
- **战斗**：状态机（BattleManager）+ 运行时单位（Battler）+ 敌人 AI 范式引擎 + 特别敌人定制 AI。
- **探索**：明雷遇敌 + Interactable 交互组件。
- **镜头调度**：Phantom Camera 插件，实现死区、跟随、固定镜头。
- **存档**：手动 6 槽，JSON 序列化（含装备）。
- **对白**：DialogBox + 命令系统（DialogueCommand）+ 分支（choose/if_flag）。
- **UI**：系统面板 / 背包 / 装备 / 角色三 tab / 商人 / 目标选择浮标。
- **操作**：键鼠 + 手柄最小映射（不改键位）。
