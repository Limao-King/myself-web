# 骰子，和构筑于之上的整个冒险旅途：《博德之门3》核心系统拆解

## 总述

DND（龙与地下城）是闻名遐迩的桌游 IP，在较现代的 DND 版本中，D20 系统是其中的核心系统——它以一颗 D20 骰子来判定行动的成功与否、剧情的后续走向，使玩家每次跑团都有独一无二的体验。

将游戏从桌面搬到电脑上的想法与尝试，开创了 CRPG 的黄金时代——《创世纪》《巫术》《异域镇魂曲》《永恒之柱》共同呈现了 CRPG 当红的时期，《博德之门2》也取得了卓越的成功。拉瑞安工作室将 D20 这套核心系统搬上了自研的高交互性引擎，辅以庞大的剧情文本、多样的剧情差分、全 CG 演出和可控的战斗曲线，最终造就了这部传世精品。

《博德之门3》由拉瑞安工作室开发，历经约 3 年 EA 打磨，2023 年发售。核心规则基于 DND 5E，是一款注重叙事选择、剧情演出、队伍互动、环境互动的叙事驱动 CRPG。

## 核心循环

角色跟随剧情探索世界，面对挑战 → 掷骰检定值决定行动奖惩，影响剧情走向 → 以奖惩更新队伍构筑，变动队伍关系 → 新的剧情走向中探索世界，面对挑战。

## 核心系统及分析

基于 DND 的 D20 系统，大到剧情抉择的成功与否，小到在蜘蛛网是否会摔倒，都由一颗最大点数为 20 的骰子所掷出的点数所决定。

### 属性与检定

这个系统要求玩家在开始游戏前通过种族、身份、职业、属性、外貌等方式创建自己的角色。其中属性十分重要，它与 D20 的检定系统息息相关，从六个维度衡量玩家创建的角色的能力——力量、体力、敏捷、智力、感知、魅力。创建时最低值为 8，最高为 21。

属性的大小会影响实际事件或行动中掷骰时带来的检定加值。其作用方式是：属性先影响熟练项，然后和熟练项一起影响对应检定的结果。

以一个简单的例子来看，撬开一户人家宝箱的行动需要 16 点才能成功，角色掷出的 D20 骰子点数只有 15，低于需要的 16。不考虑其他加减值因素的话，这次行动会被判定为失败。

但如果将敏捷和敏捷下的熟练项「巧手」一起考虑在内，走向就不同了。敏捷会为事件提供加减值，算法为：（敏捷 − 10）/ 2；巧手熟练项直接提供加值。一个敏捷为 16、巧手熟练项为 2 的角色在撬锁时的结果是：

```
15 + (16 − 10) / 2 + 2 = 20 > 16
```

那么撬锁成功，宝箱被打开——这就是属性作用于事件行动成功与否的具体案例和算法。

## 核心系统优点

无论是被动或主动的抉择，博德之门3里几乎所有的行动都要被骰子所检定。这套玩法使体验多样化，玩家创建的不同角色数值各异，都会催生出不同的游戏玩法：你可以成为吟游诗人以高超的魅力说服敌人，也可以作为力量强大的战士威吓敌人，或是干脆像刺客一样潜行干掉目标。不同玩家的体验迥异——这就是这套玩法所带来的最核心的感觉：玩家似乎真的在经历自己的故事，享受自己独有的体验。

## 出彩的设计与解法

富有深度的规则是把双刃剑，它虽然保证了理解规则的玩家可以有丰富的游戏体验，但也因规则的复杂性提高了入坑门槛；自由度极高的选择和多样的故事走向，也很容易催生各式各样的 bug。拉瑞安工作室通过在诸多细节上的用心雕琢，在很大程度上解决了这些难题。

### 轻量化设计的平衡

DND 5E 的规则在龙与地下城中算是比较简单的，但对不少新生代电子游戏玩家仍存在门槛。博德之门3里，诸如豁免、感知周围陷阱等许多检定是静默自动完成的；游戏提供快捷键高亮可交互物品，鼠标指针可以直接显示攻击的成功率；基本只有庄重的事件对话场合，骰子的判定才会格外显眼。

这种轻量的设计让初次上手的玩家无需熟悉具体规则，也能在关键剧情节点享受摇骰子决定剧情走向带来的乐趣。而想深入了解游戏机制的玩家，也可以通过战斗行动日志查看每一次行动具体的数值判定。

### 拉氏房规

在跑团的概念里，不同的房间和剧本，房主可以有不同的设定，俗称「房规」。博德之门3的房主显然安排好了许多东西只为让玩家玩得开心——比如源自前作《神界：原罪2》引擎里水和电会导电、火会点燃油面的元素反应系统；又比如分发的多样化武器与装备、全 CG 实时渲染的剧情演出、和队友发展特别的关系。这些都使这场冒险体验变得丰富而又有趣。

### 可控的自由世界与认真的迭代

在这个世界里，玩家可以不拘一格、发挥想象力自由冒险。对于重重嵌合、相互影响的剧情，工作室做了在关键节点进行收束的处理——例如无论帮助了地精部落还是林地，最终走入第二章都得去月出之塔。这样的处理可以保证玩家所有的自由在一个可控的框架之下。

游戏还是可能出现层出不穷的 bug，拉瑞安对此做了最淳朴的做法：以长期的 EA 接受玩家反馈，不断迭代修补，最终才造就了这部优秀作品。
