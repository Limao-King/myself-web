# 各地区发展概论

上元古界世界观的核心文档：论述大陆各文明如何起源、初具规模、发展繁盛为大帝国，又因何转衰、走向终局。各地域按「玄沌、晕始、复沌、元启、下元、中元、上元」的时间顺序叙述，覆盖夏、大漠荒山、扶余、冰原、日耀等文明。

节选：

**序**：本文意在说明上元古界各地区文明的"起承转合"——这片大陆各文明如何起源、初具规模、发展繁盛变为大帝国，又因什么问题转衰、没落，然后走到终局。各地区将按「玄沌、晕始、复沌、元启、下元、中元、上元」的时间顺序叙述，简单的时期分化带着对该时期的寓意（类似西方的黑铁、白金、黄金时代）。

**夏 · 玄沌时期：混乱与缓慢**

玄沌时期的上元大陆存在少量的部落，因种群优势与资源丰富，雪猫人一族及密林一族在早期的发展相对领先。密林一族具有早期的神明崇拜与特色工艺；雪猫人一族在这一时期则可谓是雪原之王。

那时，伫立在上元大陆东南一隅的淤泥质沙岸东向眺望，可以看到一片涡流状的山体——海中之屿。百万年前，此处是大海的中心，中心断层涌出熔岩，历经抬升，之后地衣苔藓、水藻青蕨、丰草珊瑚、飞鸟海鱼，成为夏民族的发源。

海中之屿的夏族尚是一批原始民，以血缘分化成群体，分在岛上各部居住。血缘的鄙视与资源的限制使得各部族长期竞争，割立的各个小部落谁也壮大不起来，发展滞缓。
