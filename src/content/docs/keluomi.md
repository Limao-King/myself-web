# 克罗米的鬼巫

巫术题材舞台剧剧本，带实验性的内心投射写法，共四幕。

**角色表**：
- **A**：取得学士，正在印书的工坊做零工以筹划修读硕士的青年，热爱法学，富有理想，正义，渴望实现抱负。有酗酒的习惯。
- **a**：A 在书上的内心投射。
- **工坊老板**：一位略有刻薄的老板，对 A 关心。
- **B**：A 的朋友，一位经营肉铺的酒徒，有一只宠物猫大咪。
- **C**：A 的朋友，硕士，计划去乌普萨拉修习神学的青年。
- **酒徒 D、酒徒 E**：酒徒。
- **F**：一位哑巴。
- **F'**：A 在 F 的内心投射。
- **男观众 G、女观众 H**：观众。
- **I**：受总督命令，调查克罗米小镇巫术事件的大臣。

**写法说明**：`A：`为人物台词／动作；`[`为舞台备注；`【】`为面对观众的独白语句；`（）`为动作描写。
