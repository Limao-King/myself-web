# 克罗米的鬼巫

巫术题材舞台剧剧本，带实验性的内心投射写法。

**主要角色**（节选）：A——取得学士、在印书工坊做零工以筹划攻读硕士的青年，热爱法学、富有理想，有酗酒的习惯；a——A 在书上的内心投射；工坊老板；F——一位哑巴；I——受总督命令调查克罗米小镇巫术事件的大臣。

**写法说明**：`A：`为人物台词／动作；`[`为舞台备注；`【】`为面对观众的独白语句；`（）`为动作描写。

A：（停下，抬手，像在挥鞭）架，驾！不走，不走了。再怎样我也不走了……前面分明跟地狱没有区别，而我逗留的地方虽然荒凉，时间却在这里被静止了，没有快乐也没有悲伤。
