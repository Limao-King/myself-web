# 序章剧情

战争军事题材的剧本式开场，节选如下：

## 0-0 悬崖，日夏军交战地

商启：（坐地，俯视）骑兵一千……两翼。步军三千。

商启：……后勤，五百。（指）

花胤：那是，敌军的先遣队？

商启：是啊，大战要来了。

花胤：讷字旗……

商启：讷氏。先前在夏日之战积累功勋，如日中天的大家族。

商启：我们的机会来了。

花胤：是啊。一定要打场大胜仗！让那些嚼舌根的酸猴们看看我花家的厉害。

商启：（……我会建立功勋，人生的第一回战斗。）

（鸟，疾速掠影）

花胤：诶呀呀！！吓我一跳，刚刚那是……

商启：第一步。

商启：该回营地了。

## 0-1 峦原，夏军军营

轲云：第十五军，随我出列！

轲云：全军，目标，陵丘。行进！

轲云：（娘的，又是这种无关紧要的破差事，还要带这种朱门里面的娃娃兵。）
