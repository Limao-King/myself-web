# 历史年表

上元古界跨年代的文明发展时间线（Excel 表格），按地域（夏 / 日耀 / 雄国 / 飞鹰 / 大漠 / 荒山 / 扶余）记录关键事件。节选如下：

## 玄沌时期（BC30–BC1）
- **夏**：岛上的初等文明萌芽，以血缘分化。
- **密林**：初步发展，产生部落，有早期神明崇拜与工艺。
- **雪猫人**：产生初等文明，发展停滞。
- **大漠**：仍是采集者而非农耕者；**荒山**：民风彪悍的部族出现。

## 晕始时期（前 174–前 21）
- **夏**：以滨州一族为首迁居中原（海中之屿的"远渡试炼"）。
- **密林**：产生小联盟。

## 复沌时期（前 21–30 年）
- **前 21–元年**：中原稳定，珂臣成为早期统治者。
- **元年–12 年**：珂臣暴政，鳌立刺杀事件；龙玄周出生为元年。
- **12–20 年**：龙玄周被推举上位，灵巫掌权。
- **20–30 年**：文化盛世，盘钰、商泊出生；大漠雏形出现。

## 元启时代（30–67 年）
- **30–45 年**：龙玄周夺回实权、发起改革，兴修中原都城。
- **45–55 年**：分封诸亲。
- **55–67 年**：永安城完工，**宣告建夏**（立国仪式），饕餮事件。

## 下元时期（67 年起 · 分裂）
- **67 年**：龙玄周去世，商泊上位（分界线）；盘钰、子让、九炙被流放；玄鶕出逃荒山、盘钰到达扶余。
- **67 年末**：商泊发动清洗、改革；九炙传播技术；子让建立冰原大部落雏形；盘钰开始四处征讨。
- **68 年**：冰原大部落建立；承运坛建成、**扶余建国**。
- **70–90 年**：飞鹰与雄国雏形形成；一号改革、神谱梳理；盘钰遇刺、十炬上位扩军。
- **90–94 年**：第一次对夏战争开始；海州之战；暮离让贤罗然，罗然分权改革。
