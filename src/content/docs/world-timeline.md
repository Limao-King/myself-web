# 历史年表

上元古界跨年代的文明发展时间线（Excel 表格），按地域（夏 / 日耀 / 雄国 / 飞鹰 / 大漠 / 荒山 / 扶余）记录关键事件。

> 各时期纵向按年代推进，横向按地域铺排。不同时期有各自的一列主角：玄沌期以夏为主轴，下元期进入多国并起，中元期战火延烧诸国，上元期则步入天下既定。

## 玄沌时期（BC30–BC1）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 玄沌 | 夏 | 夏族在岛上发展出初等文明，并以血缘分化。 |
| 玄沌 | 密林 | 密林一族初步发展，产生部落。 |
| 玄沌 | 雪猫人 | 雪猫人产生初等文明，发展停滞不前。 |
| 玄沌 | 大漠 | 发展落后，仍然是采集者而非农耕者。 |
| 玄沌 | 荒山 | 产生部落，当地民风彪悍。 |

## 晕始时期（前 174–前 21）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 晕始 | 夏 | 以滨州一族为首的夏族人迁居中原。 |
| 晕始 | 密林 | 密林一族产生了小联盟。 |
| 晕始 | 日耀 | 狂觉上位。 |

## 复沌时期（前 21–30 年）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 前 21–元年 | 夏 | 中原地区稳定下来，珂臣成为早期的统治者。 |
| 元年–12 年 | 夏 | 珂臣暴政。鳌立刺杀事件。以龙玄周出生为元年。 |
| 12–20 年 | 夏 | 龙玄周被推举上位。灵巫掌权。 |
| 20–30 年 | 夏 | 文化盛世。盘钰出生，商泊出生。 |
| 20–30 年 | 大漠 | 24 人，大漠雏形（30 年）。 |

## 元启时代（30–67 年）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 30–45 年 | 夏 | 龙玄周夺回实权，发起改革。子让、九灸出生。兴修、扩大中原都城，名永安。暮离出生，罗然出生。 |
| 45–55 年 | 夏 | 分封诸亲。玄机、玄鶕双胞胎出生。十炬出生。 |
| 55–67 年 | 夏 | 永安城完工，宣告建夏。饕餮事件。子仲、子伯相继出生。 |

## 下元时期（67 年 · 分裂期）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 67 年 1、2 月 | 夏 | 龙玄周去世。商泊上位。（分界线。） |
| 67 年 3、4 月 | 夏 | 盘钰、子让、九炙被流放。 |
| 67 年 3、4 月 | 雪猫人 | 雪猫人发明铁器。 |
| 67 年 3、4 月 | 荒山 | 荒山瘟疫爆发。瓦剌灸嗣出生。 |
| 67 年 5–8 月 | 夏 | 玄鶕出逃。 |
| 67 年 5–8 月 | 密林 | 九炙到达密林。元思、马乌出生。 |
| 67 年 5–8 月 | 荒山 | 玄鶕到达荒山。 |
| 67 年 5–8 月 | 扶余 | 盘钰到达扶余。百人乱斗，确立统治。 |
| 67 年末 | 夏 | 商泊发动清洗，进行改革。 |
| 67 年末 | 密林 | 九炙开始传播技术。 |
| 67 年末 | 冰原 | 子让到达冰原，建立冰原大部落的雏形。 |
| 67 年末 | 荒山 | 玄鶕开始胡言乱语。 |
| 67 年末 | 扶余 | 盘钰启程，开始四处征讨。 |
| 68 年上旬 | 夏 | 商泊年长得子，周宗宪出生。九讷出生。 |
| 68 年下旬 | 夏 | 玄机遇刺，临刺之前托稿。 |
| 68 年下旬 | 冰原 | 冰原大部落建立。 |
| 68 年下旬 | 扶余 | 承运坛建成，扶余建国。 |
| 69 年 | 冰原 | 子让进入分队。子仲、子伯发生第一次分歧。独眼出生。 |
| 69 年 | 扶余 | 盘钰改革。九邦得到任用。 |
| 70–80 年 | 密林 | 九炙进入决策层。 |
| 70–80 年 | 飞鹰·雄国 | 子仲、子伯分队。飞鹰和雄国雏形形成。 |
| 70–80 年 | 荒山 | 心湖瘟疫开始爆发。 |
| 80–90 年 | 夏 | 一号改革，前期。神谱梳理。穷奇事件。 |
| 80–90 年 | 夏 | 建立第一个居住区。子仲去世，暮离上位。 |
| 80–90 年 | 扶余 | 盘钰遇刺，十炬上位，开始扩军。 |
| 90–92 年 | 夏 | 商泊去世，周宗宪上位。龙王月出生。 |
| 90–92 年 | 扶余 | 板马发现，建州。 |
| 92 年 1、2 月 | 扶余 | 遭遇扶余攻击。建立军事城镇。石根草改良成功。第一次对夏战争开始。 |
| 92 年 3、4 月 | 夏 | 周宗宪御驾亲征，到达西挪山地区。暮离让贤罗然。 |
| 92 年 4–12 月 | 夏 | 海州之战。 |
| 93–94 年 | 夏 | 周康出生。马乌上位，子伯去世。罗然开始进行分权改革。 |
| 93–94 年 | 扶余 | 十炬遭遇刺杀。瓦剌灸嗣上位。 |
| 94–104 年 | 日耀 | 日耀混战。九炙进行神祭。九炙去世，九讷上位。 |
| 94–104 年 | 扶余 | 西进运动，武备晋升。确立寒威刀为货币。雪霁区叛乱。大议会设立。 |
| 94–104 年 | 飞鹰 | 签订《八港约》。修缮斗技场。创立护法军。 |
| 104–120 年 | 夏 | 李煌出生。一号改革，后期。 |
| 104–120 年 | 荒山 | 匝嘛上位，军功改革。 |
| 104–120 年 | 雄国 | 第一次中挪山战争。力努攻入首都（117）。炙嗣自杀，瑶光上位。 |

## 中元时期（121–227 年 · 大混战）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 121 年上旬 | 夏 | 周宗宪姓名改革。 |
| 121 年上旬 | 夏 | 铎上位。（分界线。）二号改革开始。与荒山发动战争。罗然去世，穆肃上位。久塬出生。 |
| 121 年下旬 | 夏 | 第一次日夏战争（121–127）。 |
| 121 年下旬 | 雄国 | 第二次中挪山战争。 |
| 121 年下旬 | 雪猫人 | 第二次雪猫人屠杀。 |
| 122–132 年 | 夏 | 取消自治领的自治权。元思上位。匝嘛、马乌去世。 |
| 122–132 年 | 飞鹰 | 对巨熊求和。龙王月上位。龙王月改革。独眼演讲。 |
| 132–147 年 | 夏 | 周宗宪去世，周康上位。日耀大混战开始。 |
| 132–147 年 | 荒山 | 独眼去世，软上位。捕捉雪猫人。 |
| 132–147 年 | 雄国 | 五元之乱开始。允许寺院组织军队。久塬开始征讨（147）。 |
| 147–162 年 | 夏 | 泊郡起义。周康被杀，李煌上位，李煌改革。人间宣言发表（162），铎位子被废除。诺麓阿出生。 |
| 147–162 年 | 扶余 | 久塬废除扶余王（171）。神清寺大火。宪刚被流放。 |
| 162–177 年 | 夏 | 李煌去世，李暮上位。铎去世，二号改革结束。 |
| 162–177 年 | 飞鹰 | 龙王月去世，列上位，为人运动。 |
| 162–177 年 | 扶余 | 久塬收回私兵权。重修神清寺。修凌霄书院。 |
| 177–189 年 | 夏 | 李暮去世，夏氏篡权，夏氏改革。 |
| 177–189 年 | 日耀 | 讷氏垄断朝政。讷忒屑上位（181）。 |
| 177–189 年 | 日耀 | 蒯祈杀死元思。（179–182 无君主。）诺麓阿上位，猎巫。 |
| 177–189 年 | 雄国 | 获得十二洲（182）。久塬去世。 |
| 189–202 年 | 夏 | 夏氏衰微，权力转移。废除所有自治权。三号改革。 |
| 189–202 年 | 荒山 | 诺麓阿获得穷奇之心。巨熊建国，定都所若。 |
| 189–202 年 | 雪猫人 | 冰惩制作成功。软去世，泽上位。 |
| 202–215 年 | 夏 | 周屹上位。第二次日夏战争。 |
| 202–215 年 | 日耀 | 元思去世。 |
| 215–227 年 | 日耀 | 日耀发动反攻（214），败走。 |
| 215–227 年 | 夏 | 开始对夏的侵略。晴荣出生。 |
| 227–234 年 | 夏 | 周屹彻底击溃雄国入侵。（分界线。） |

## 上元时期（234–269 年 · 天下既定）

| 年代 | 地域 | 事件 |
| --- | --- | --- |
| 234–242 年 | 夏 | 定都为天。 |
| 242–247 年 | 夏 | 黎稷城基本完工。晴荣上位。 |
| 247–252 年 | 夏 | 周屹晚年重病，多子开始争权。晴荣巡视板马州。 |
