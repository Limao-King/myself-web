# 第一章 · 想象的力量

> 用途：对白 04 剧情战胜利后自动触发。含皮皮入队、世界观揭示与「技能解锁」事件（安娜解锁 fantasy_bubble、汉斯解锁 fiction_hand）。

安娜：我叫安娜，这是我哥哥，叫汉斯。

安娜：所以？你的名字就叫皮皮呀？

皮皮：呼呼，应该是吧。

安娜：你想不起来了吗？

皮皮：（支支吾吾）

汉斯：好可疑……

汉斯：皮皮，有一点我很好奇，你刚刚在战斗中好像只是用剑轻轻一划，就出现一股很强的气流。那个是怎么做到的？

安娜：对呀对呀。

皮皮：（自豪）呼呼，那是想象的力量。嗯？——你们应该也行呀。

安娜：真的吗？快教我怎么使用那种「想象的力量」。

皮皮：（点头）集中你的思想，捕捉你脑海里最强烈的念头，然后不断想象那个念头实现的场面……

（旁白）：跟着皮皮的话语，安娜抬起手，集中精力开始想象。

（旁白）：一个闪耀着彩虹色的泡泡竟然真的在她手上成形，安娜惊叫一声，泡泡从手上径直飞了出去。

安娜：成功了！

汉斯：（小声嘀咕）……怎么可能。

皮皮：是吧，本皮说过，本皮从来不说谎。

安娜：有说过吗？

皮皮：诶，看来是本皮记错了（挠头）。

皮皮：这位叫汉斯的少年，你不试试看吗？

汉斯：（点头）

汉斯：这到底是什么力量？皮皮。

皮皮：说实话，这股想象的力量到底从何而来，我也不太清楚。但是这里的许多居民都学会了运用这股力量。

皮皮：你们有这样的力量，但是竟然现在才发现吗？

安娜：我们平常都和爸爸生活在一起，但是想象与想象的魔法他从来也没提过……

汉斯：我也有点搞不清楚了，但是这力量有一种熟悉的感觉……

皮皮：嘶，对了，你们来这里干嘛。

安娜：噢！我们是想去找妈妈来着。对了，你来的时候有看见我们的爸爸吗？

汉斯：（比划）大概六尺来高，脸上有一道抓痕，长满胡茬，身材比较魁梧，背着猎弓，还佩着……

皮皮：完全没印象。

安娜：啊。我还想着你告诉我们，我们就可以避开爸爸了。

汉斯：安娜，我们肯定要跟爸爸先商量的。

安娜：（努了努嘴，头微点）

皮皮：不过这里一直是精怪的地盘，人类来这里很危险的。

汉斯：精怪？就是刚刚出现的那些吗。父亲打猎的森林有这些家伙吗？

安娜：安娜想不明白，不过如果有这么多精怪的话，爸爸会不会有危险！

汉斯：说得对，我们得确认爸爸的安危。

皮皮：呼呼，真是体贴的好孩子啊，让本皮也跟你们一起行动吧。

皮皮：毕竟没有宝藏猎人的指引，汝辈要如何看穿森林里的阴谋呢。

安娜：你也是猎人！

皮皮：是的，「宝藏」——猎人。

汉斯：我们快行动吧……
